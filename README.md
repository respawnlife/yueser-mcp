# yueser-mcp — Qiku MCP Directory Server

A **remote MCP server** that lets AI assistants look up MCP servers with *measured* data: what tools a server actually exposes, what permissions it declares, and how to configure it.

**Endpoint:** `https://ai.yueser.com/mcp` · Streamable HTTP · read-only · no API key · no signup

Qiku (器库) is a Chinese-first MCP directory. This server exposes that directory to AI clients, so an assistant asked "which MCP server should I use for X?" can answer from a catalogue instead of from memory.

## Quick start

### Cursor — `~/.cursor/mcp.json`

```json
{
  "mcpServers": {
    "qiku": { "url": "https://ai.yueser.com/mcp" }
  }
}
```

### Claude Desktop — `claude_desktop_config.json`

```json
{
  "mcpServers": {
    "qiku": { "url": "https://ai.yueser.com/mcp" }
  }
}
```

### Cline — `cline_mcp_settings.json`

```json
{
  "mcpServers": {
    "qiku": {
      "type": "streamableHttp",
      "url": "https://ai.yueser.com/mcp"
    }
  }
}
```

> The `type` field matters: without it Cline treats the entry as a stdio server.

### VS Code — `.vscode/mcp.json`

```json
{
  "servers": {
    "qiku": {
      "type": "http",
      "url": "https://ai.yueser.com/mcp"
    }
  }
}
```

> VS Code uses `servers`, not `mcpServers`.

Restart the client and ask it something like *"use qiku to find MCP servers for GitLab"*.

## Tools

| Tool | What it does |
|---|---|
| `search_mcp_servers` | Search servers by keyword, category, or declared permission; optionally only probed ones |
| `get_mcp_server` | Full profile: exposed tools and their parameters, permissions, version, license, maintainer, probe date |
| `get_config` | Generate a paste-ready client config (Claude / Cursor / Cline / VS Code) with env placeholders and credential instructions |
| `search_tools` | Search Qiku's browser-local utility tools (image, PDF, text, encoding, calculators) |
| `list_categories` | List all categories with server counts |

## What's in the data

- **756 MCP servers** indexed, 12 categories
- **596** have been actually probed (`initialize` + `tools/list`)
- **600** have per-tool detail captured
- **369** carry permission labels (read / write / credential) — these come from each service's own declarations
- **93** include configuration hints (install command, env vars, credential steps)

### Scope and honesty

This is the part most directories skip, so it is stated plainly:

- **Permission labels are declarations, not verdicts.** They come from each service's README or service metadata. Qiku draws no security conclusion — verify before use.
- **Unlabeled entries say so.** Nothing is implied to be safe by omission.
- **Probe data has a time window.** Every search result carries the data cutoff date; it may not reflect a server's current state.
- **Probe coverage is partial.** Where a probe could not reach a server, the tool list is filled from the official README and **labelled as such**. The two sources are never conflated.
- **Tool counts vs captured detail differ sometimes.** A server may expose more tools than we captured; the output distinguishes "recorded" from "not captured".

## Why not just registry metadata

Most MCP listings are scrapes of package registries: name, version, description. That tells you a server exists — not what it does to your machine.

This directory is built around probing: connect, call `tools/list`, record what comes back, and classify what the server can touch. The result is a catalogue you can ask *"which of these can write to my database?"*, not just *"what packages are called mcp-something"*.

## Self-hosting / development

The server is deliberately **zero-dependency** — Node built-ins only (`node:http`, `node:sqlite`, `node:readline`). No `npm install` required.

Requires **Node >= 22.5** (`node:sqlite` is built in from that version).

```bash
node build-db.mjs          # build the SQLite read model from JSON source data
node server.mjs            # HTTP mode, default 127.0.0.1:7701, endpoint /mcp
node server.mjs --stdio    # stdio mode, for local clients
```

`build-db.mjs` expects a JSON data directory (`--data`, default `../yueser-data`). **The production dataset is not included in this repository** — it is generated by Qiku's private content pipeline. The code is published so the transport, tool schemas and data model can be inspected and reviewed.

Architecture:

```
JSON source data  ──build-db.mjs──►  data.sqlite  ──server.mjs──►  MCP over HTTP / stdio
```

JSON stays the source of truth (diffable, reviewable); SQLite is a derived read model.

If you maintain an MCP server and want it listed in the Qiku directory, open an issue using the **Submit an MCP server** template in this repository. Submissions are reviewed manually; listing is free.

## 器库 MCP 服务（中文）

把器库的中文 MCP 目录做成一个 MCP 服务器。装上之后，AI 助手可以直接查每个 MCP 服务器**实际暴露了哪些工具、需要什么权限、怎么配置**——而不是凭记忆猜。

**端点：** `https://ai.yueser.com/mcp` — 只读、无需密钥、无需注册。

接入方式见上方 Quick start；更详细的三语说明在 **https://yueser.com/agent/**

### 数据口径

- 收录 **756** 个 MCP 服务器；**596** 个经过实际探测（`initialize` + `tools/list`）
- **369** 个有权限标注——来自各服务自身声明，器库不下安全结论
- 探测覆盖不到的条目按官方 README 补录并**标注来源**，不与探测结果混为一谈
- 所有查询结果都会带上数据截至日期
